Для ClusterIP используйте Kubernetes API и отдельное разрешение GET services/proxy. Если источник собирает только этот кластер, явно выберите «Выделенный» ниже; иначе нужны метки кластера.

Заполните поля выбранного подключения. После сохранения Pulse проверит настройки обратным чтением API. Метрики появятся после успешного доступа к источнику.

HolmesGPT · отдельный read-only агент

Генерация создаёт отдельные токены, 12 сценариев проверки и read-only tools только этого кластера. Сначала запустите Holmes на сервере и проверьте ответ, затем включите режим.

ИИ Astra · анализ через её API

Сначала сохраните настройки и проверьте поток. Токен вводится только здесь, значение обратно не возвращается. Анализ получает собранные Pulse доказательства. Обрыв потока помечается ошибкой без скрытого переключения модели.
