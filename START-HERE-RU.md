# Pulse Clusters 0.16.0: с чего начать

1. Для сервера с Pulse 0.15.1 откройте [UPDATE-0.16.0-RU.md](docs/UPDATE-0.16.0-RU.md). Он использует `/opt/services/pulse/runtime`, сохраняет рабочие ключи/настройки, создаёт backup и rollback. Повторный `init` не требуется.
2. После обновления: Ctrl+F5 → Обзор → ✧ у известной проблемы → Полный разбор. Если модель недоступна, смотрите конкретную ошибку в диалоге и trace источников. История очищается при новом открытии.
3. Локальный vLLM и его две A30 сохраняются. Укажите базовый URL и alias `qwen`, проверьте настоящий путь анализа скриптом из инструкции обновления. Не выбирайте модель по имени каталога и не меняйте GPU/контекст для исправления ошибки формата Pulse.
4. Затем подключите [AI-стек](docs/AI-STACK-RU.md): Qdrant, CPU embeddings, Holmes и MD-библиотека. Не запускайте второй сервис на порту уже работающего Holmes/Qdrant. Сначала тестовые документы, потом полный архив.
5. Приёмка: причина по доказательствам, подходящие версии документов, реальные инструменты Holmes, корректные имена команд, честные пробелы и проверка восстановления приложения. `done` — завершение генерации, не автоматическое доказательство диагноза.
