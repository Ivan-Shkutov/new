# Pulse: предварительный макет сценариев

Макет для просмотра перед переделкой приложения. Рабочий Pulse остаётся **0.14.7 / 39e2f01092c3446a**; новая версия приложения не выпускается на этом этапе. Данные, статусы и прохождение проверок в макете демонстрационные. Нет запросов к API Pulse, модели или кластеру.

## Названия

1. Краткий разбор — суть, важность, причина, первый шаг.
2. Подробный разбор — события, логи, связи, неизвестное.
3. Причины сбоя — подтверждённая причина и проверяемые гипотезы.
4. Последствия сбоя — фактическое влияние и возможные риски.
5. План устранения — последовательность действий и команды для оператора.
6. Проверка восстановления — свежая проверка готовности и доступности.

## Вид

- Слева выбор сценария, справа один результат. Свободного вопроса и ленты переписки нет.
- Краткий разбор укладывается в четыре строки. Доказательства закрыты по умолчанию; частичная доступность данных видна сразу.
- План устранения предлагает команды чтения и условные рекомендации. Готовность замены определяется через владельца; старый Pod не выдаётся за работающую реплику.
- Проверка восстановления не заявляет успех без новых данных.
- История и хранение существующих расследований — отдельный вопрос реализации; этот макет ничего не удаляет.

Откройте [index.html](index.html) как обычную HTML-страницу. Все шесть кнопок работают с демонстрационным контентом. Выбранный сценарий сохраняется только в URL hash; переписка/credentials не используются.

Изображения: [краткий разбор](preview-brief.png), [план устранения](preview-plan.png), [восстановление](preview-recovery.png), [мобильный экран](preview-mobile.png).

Проверено в Chromium: шесть сценариев, быстрое переключение, закрытые доказательства, отсутствие поля вопроса, неподтверждённый статус восстановления, ширины 1440/1366/390 px, отсутствие запросов к API/внешним сервисам. Проведена независимая проверка названий и достоверности формулировок.

При реализации нужны отдельные планы проверок и контракты результатов. В этом HTML `innerHTML` используется только для фиксированных доверенных заглушек; реальные ответы LLM следует выводить через безопасный renderer Pulse, не вставлять как HTML.
