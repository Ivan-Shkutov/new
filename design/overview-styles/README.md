# Четыре визуальных исполнения Обзора D+B

Дата: 29 октября 2026. Варианты оформления для выбора пользователем; код рабочего приложения этим изменением не заменяется.

Во всех вариантах одинаковый набор: три круга CPU/RAM/дисков с историей, семь карточек DaemonSets/Deployments/Jobs/CronJobs/ReplicaSets/StatefulSets/Pods, состояния источников и проблемы. Различаются компоновка, плотность, цвет и иерархия внимания.

| № | Исполнение | Основная идея | Компромисс | Изображение |
|---|---|---|---|---|
| 1 | Pulse Dark | Тёмно-синий фон, бирюзовые акценты, цветные круги и графики, сбалансированный обзор | Для нижних блоков может требоваться прокрутка | [Открыть 1](variant-1.png) |
| 2 | Headlamp Light | Светлый фон и строгие чёрные круги, высокая читаемость таблиц и подписей | Меньше цветового выделения готовности | [Открыть 2](variant-2.png) |
| 3 | Control Room | Компактная навигация, семь workloads в один ряд на широком экране, карта трёх кластеров | Мелкие подписи, выше плотность информации | [Открыть 3](variant-3.png) |
| 4 | Focus | Фиолетовые акценты; проблемы, источники и qwen в правой колонке; карта кластеров снизу | Больше прокрутки, менее плотная сетка workloads | [Открыть 4](variant-4.png) |

Рекомендация: **1** как основной ежедневный интерфейс. **3** — если важнее увидеть максимум показателей на одном мониторе. **4** — если основная работа связана с расследованиями и локальной LLM. Возможна комбинация: оформление 1 + компактность 3 + правая колонка 4.

## Интерактивный просмотр

Скачайте [index.html](index.html) через **Download raw file** и откройте на своём компьютере. Файл автономный: CSS, SVG и JavaScript включены, сетевых запросов к кластерам и внешних библиотек нет. Кнопки 1–4 переключают исполнение. Переключатель времени демонстрирует выбранное состояние; данные графиков в макете не перезапрашиваются. Кнопки ресурсов и расследования открывают демонстрационную карточку. Это визуальная презентация, не отдельный установщик приложения.

## Данные и ограничения

- Числа 6 nodes / 163 pods / 14 namespaces взяты из ранее присланного снимка PeopleHub; это не текущая инвентаризация.
- CPU 38%, RAM 64%, диски 72%, ёмкости, количества workloads и проблемы вымышлены для согласованного сравнения всех четырёх макетов. Они явно помечены как демонстрационные.
- Backend и Frontend показаны как ожидающие подключения, исходя из имеющейся информации.
- Успешный ответ qwen из Pulse подтверждён пользователем ранее. В макете LLM не вызывается.
- Готовность контроллеров/Pod, завершение Jobs и включённость CronJobs подписаны отдельно. Круг CronJobs не является оценкой успешности последних запусков.
- В существующем 0.7.0 дисковый показатель ограничен корневой ФС `/` узлов; дополнительные mountpoints и PVC требуют отдельных показателей. Абсолютные ёмкости на этих макетах требуют добавления соответствующих данных в API при реализации.
- Оформление 2 ориентируется на визуальный подход Headlamp из пользовательского примера. Код и изображения стороннего продукта не копировались.

## Проверка макетов

В Chromium проверены четыре desktop-исполнения (1600 px), mobile (390 px), отсутствие горизонтального переполнения страницы, три кольца утилизации и семь workload-карточек в каждом варианте, переключение периода и открытие/закрытие карточки. Ошибок JavaScript не обнаружено. Приложение, Docker и реальные источники этим просмотром не изменялись.
