# Аудит и границы Pulse 0.16.0

Проверены маршруты API, временные сессии, коннекторы Kubernetes/метрик/Astra/LLM/Holmes, правила, база знаний, импорт, frontend и установка. До изменений весь набор: 529 passed. Это аудит доступных исходников и локальных контрактов, не утверждение об отсутствии всех ошибок.

## Исправлено

- Основной путь больше не направляет каждую кнопку в строгое JSON-дополнение `{hypotheses, checks}`. Обычный законченный ответ принимается в новом диалоге; старые API сценариев сохранены и проверяются отдельно. Исторический production-отказ по одним скриншотам не локализован: исправлено подтверждённое несоответствие интерфейса/контракта, а не заявлена непроверенная первопричина.
- Диалог из Обзора, очистка при новом открытии, продолжение только в этой сессии. Точная цель и digest подключений привязаны к диалогу. Исправлена передача namespace/name/UID из Ресурсов. Для иных поддерживаемых объектов читаются live-данные, не только снимок.
- Настраиваемые лимиты: native 8192/300 секунд, валидированные пределы, reasoning-only/truncation остаются ошибками. Astra сохраняет наблюдавшийся request contract; max_tokens отправляется только при явном сохранении этого поля для Astra. Holmes 8 итераций/4096/180 и отдельное ожидание 600 секунд. Поднятие клиентского таймаута не меняет таймауты Astra Gatekeeper/nginx.
- Видимая причина ошибки, безопасный run_id/code/latency trace и usage, если провайдер её вернул. HTTP 200 не является критерием законченного анализа.
- Процесс расследования с остановкой по доказательствам/лимиту, правила OOM/VK Почты/Astra и условные действия с проверкой/откатом. Проверки остаются read-only, изменение кластера автоматически не выполняется.
- Обновление сгенерированного bundle Holmes с приватной копией и сохранением URL/credentials/Compose. Требуется перезапуск сервиса; чужой отдельный Holmes не редактируется.
- Markdown-aware chunks-v2, FTS по опубликованной библиотеке вместе с векторным поиском, D## и каталог источников до генерации. Без embeddings остаются доступными опубликованные лексические совпадения с явной отметкой о vector-ошибке.
- MD-only ZIP/TAR importer/watcher, preflight путей/ссылок/лимитов, idempotence, отчёт и UI. Не удаляет отсутствующие в новом архиве документы автоматически.
- Upgrade принимает пустой backup-каталог, что устраняет наблюдавшийся FileExistsError; поддерживает проверенное переключение current и его откат. Runtime, ключ, пароль и прежний образ сохраняются.

## Что ещё требует реальной приёмки

- Качество текущей Qwen и настоящий tool calling через конкретные веса/template/parser. Reasoning parser не равен tool parser. Нужны проверка nonce инструмента Holmes и известные инциденты с правильными выводами.
- Фактические права/контракты API Astra logs, наличие исторических событий/логов, доступ к Prometheus и прикладной проверке VK. Недоступные данные не становятся нулевыми или здоровыми.
- Реальная BGE-M3/Ollama, качество выдачи и соответствие версий. Тестовые embeddings проверяют контракты, не семантическую точность.
- Разрешённый доступ к образу Holmes, его API/версия. Контракт адаптера закреплён на 0.45.0; образ и модель не выданы за запущенные без проверки.
- Agent HTTP timeout — ожидание клиента, а не немедленная отмена удалённого model/tool вызова. Общая задержка зависит от сервера агента и очереди vLLM.
- Автофильтр версий сейчас реализован для Kubernetes; для VK/Astra обязательно проверять версию документа, не смешивать SaaS и on-prem. Полнота архива неизвестна до импорта/сверки.
- Чанки ограничены символами, не точным tokenizer; длинные блоки продолжаются частями. Корпус ограничен 500 млн символов и индексируется последовательно. Нагрузочная/HA-приёмка не заменяется локальными тестами.

Не добавлены n8n и произвольный shell-агент. Для текущей цели они не устраняют ошибку анализа и усложняют критический путь. n8n можно подключить позднее для расписаний, уведомлений и задач.

## Развёртывание

На скриншотах ранее использовался HTTP-вход через временный Caddy. Для внешнего доступа используйте существующий HTTPS deployment и реальную аутентификацию администратора; proxy, автоматически добавляющий Authorization, нельзя считать защитой от анонимного внешнего доступа. Точная конфигурация действующего прокси из этой среды не читалась. Данные ключей в runtime/backup требуют сохранения закрытых прав.
