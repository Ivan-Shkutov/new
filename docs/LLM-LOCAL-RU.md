# Локальная LLM в Pulse 0.16.0

Основной путь — Обзор → ✧ → единое окно анализа. Выберите движок в «Подключение ИИ»: локальную LLM напрямую или настройки кластера. При включённом Holmes/Astra выбор «настройки кластера» обращается к нему; прямой режим не использует его credentials и не меняет сохранённый выбор кластера.

В Настройки → Локальная модель: базовый URL `http://127.0.0.1:8002/v1`, model `qwen` (проверьте `/v1/models`). Полный путь `/chat/completions` в поле базового URL не нужен. API key пустой, если vLLM не требует авторизации. Токены в исходники и чат не вставляйте.

По умолчанию native adapter: `stream=false`, `temperature=0.1`, `max_tokens=8192`, `timeout_seconds=300`. Пределы UI/API: 256–32768 токенов, 15–900 секунд. Пользовательские сохранённые значения сохраняются. Общий контекст приложения по умолчанию до 240 000 символов с единым лимитом для всех сообщений; это не tokenizer и не параметр `max-model-len` vLLM. Доказательства уплотняются с сохранением E## и полноты, а не бесконечно наращиваются.

Ранее подтверждено пользователем: GET моделей и короткий SSE из контейнера Pulse завершались HTTP 200 / `[DONE]` / `finish_reason=stop`. Это не проверяло native путь Pulse со `stream=false`, длинный контекст и старый JSON-валидатор сценариев. В 0.16 основной диалог принимает обычный текст и показывает конкретную ошибку, а старый API сценариев продолжает проверять собственную JSON-схему.

[Реальная приёмка выбранного инцидента](UPDATE-0.16.1-RU.md#3-проверить-реальный-анализ): `scripts/check-ai-integration.py`. Диагностический отчёт не включает raw evidence или ключи. Сверьте ответ с исходными фактами и настоящим исходом; semantically correct не выводится из HTTP 200.

Правила `ai_rules/BASE.md`, `KUBERNETES.md`, релевантные `NETWORK.md` и `INVESTIGATION.md` плюс выбранные runbooks реально включаются в системный контекст. Для полного первого разбора — шесть разделов до 450 слов; уточнение отвечает по теме без повторения отчёта. Для строгого совместимого API контракт JSON имеет приоритет. Веса модели правилами не переобучаются.

Native adapter не исполняет tool_calls и требует непустой финальный content с `finish_reason=stop`; один завершённый ведущий `<think>` отделяется от текста. Поля reasoning/reasoning_content не выдаются за ответ. Неполный ответ хранится только как черновик в раскрываемых источниках и не считается успешным анализом. Чтобы использовать инструменты, настройте и проверьте Holmes, включая nonce-тест.

[Holmes/Qdrant/библиотека](AI-STACK-RU.md). Не копируйте общие vLLM parser flags в работающую конфигурацию без проверки поддержки конкретными весами и версией сервера.

Для двух A30 очередь расследований Pulse по умолчанию: один активный и один ожидающий запрос, ожидание до 60 секунд. Изменение `PULSE_AI_WORKERS`, `PULSE_AI_QUEUE`, `PULSE_AI_QUEUE_WAIT` в runtime `.env` применяется после `pulse start-offline`. Текущие значения видны в защищённом `/api/settings`. Отмена ожидающего запроса не отменяет уже начатую удалённую генерацию.
