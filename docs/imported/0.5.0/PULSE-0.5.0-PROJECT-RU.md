# Pulse: единая спецификация по диалогу

26 октября 2026 года. Это сводка предоставленного диалога, требований и фактов из ваших команд, а не дословный экспорт всех сообщений ChatGPT или новая инвентаризация серверов.

## Главная цель

Один веб-интерфейс Pulse для нескольких Kubernetes-кластеров: подробное состояние инфраструктуры, отдельные проблемы, объяснение по кнопке «!», контекстный чат, локальная LLM, Astra Monitoring, официальная документация и собственные подтверждённые инциденты. Новые кластеры и документы добавляются без выпуска новой версии приложения.

## Принятые решения

- Всё остаётся в Pulse; внешний Headlamp для работы не требуется. Его подход к таблицам и карточкам используется как ориентир.
- Kubernetes API отвечает за инвентарь и статусы. Списки ресурсов выдаются без LLM.
- Сбор, интерфейс и расследование разделены. Страница получает последний снимок с временем наблюдения.
- Requests/limits, allocatable и потребление — разные величины; файловые системы узлов и PVC показываются отдельно.
- Running не равен Ready; накопленные рестарты и старое Warning не объявляются текущей аварией без проверки.
- Для объяснения используются факты, логи, документы, подтверждённые инциденты и история диалога. LLM не исполняет исправления.
- Новые подключения настраиваются через веб; общий источник метрик/логов обязательно ограничивается меткой кластера.
- Документы имеют источник, версию, хеш и область доступа. Назначение бизнес-приложения берётся из внутренних документов, а не угадывается по имени Pod.
- Проверенное решение публикует администратор после устранения и проверки; гипотезы остаются черновиками.

## Что реализовано

| Требование | Реализация 0.5.0 |
|---|---|
| Одна веб-панель | FastAPI + локальные assets без CDN, один порт |
| Несколько кластеров | Общий обзор, отдельные снимки, выбор кластера, роли и история |
| Инвентарь | 22 основных типа, пагинация, владельцы, статусы контейнеров, события, дополнительные CR из конфигурации |
| CPU/RAM/disks/network | API capacity/allocatable + Prometheus/VictoriaMetrics; пробелы обозначаются |
| Проблемы | Kubernetes/metric rules, Prometheus alerts, Alertmanager webhook, scoped Astra incidents |
| Чат по «!» | Персистентное задание, контекст объекта/UID, логи и документы, продолжение разговора |
| LLM | Встроенный ограниченный агент vLLM; адаптер Holmes; OpenAI API адаптер AURA |
| Знания | FTS5 RAG, загрузка файлов в фоне, scope/version, проверенные инциденты; опциональный Qdrant |
| Подключения | Веб-форма, проверка, замена kubeconfig, приостановка; credentials зашифрованы |
| Стабильность | Фоновый сбор, сохранённые снимки, маркировка stale, очередь, ограничения агента |
| Развёртывание | Compose, wheelhouse, init/start/check/accept, перенос истории, backup/restore |

## Агенты

Встроенный агент Pulse вызывает локальную LLM и исполняет только разрешённые функции чтения выбранного кластера. Отдельный сервис агента, kubectl в контейнере и Docker socket не нужны.

Holmes опционален. Генератор создаёт для каждого кластера отдельный токен и ограниченный HTTP toolset Pulse, `max_steps: 6`. Pulse ограничивает ожидание. Его реальную работу с вашими весами Qwen нужно проверить отдельно: healthy не подтверждает качество или tool calling.

AURA подключается через OpenAI-compatible `/v1`. Это адаптер протокола, а не встроенный дистрибутив AURA. Внешний агент настраивается отдельно; собственные его инструменты не контролируются Pulse. Aurora/Hermes из обсуждения не устанавливаются: точный продукт/контракт не закреплён, для текущего решения они не требуются.

## Границы текущего выпуска

Один сервер и один API-процесс. По умолчанию SQLite WAL; Redis/Celery и отдельные микросервисы не нужны. Внешняя PostgreSQL и Qdrant поддержаны кодом, но не разворачиваются этим Compose и не прошли живую проверку данного стенда.

Kubernetes собирается фоновым периодическим LIST с пагинацией, по умолчанию каждые 30 секунд. Постоянный LIST/WATCH-контроллер в этом выпуске не реализован. После рестарта расследование получает факты заново; внутреннее состояние модели не восстанавливается.

Secret не читаются, exec не выполняется. ConfigMap показывается с metadata, ключами и связями, без значений. Полнота зависит от прав и источников; пропуски и ограниченные выборки видны в панели. Не каждый CSI предоставляет фактическое использование PVC.

Официальный каталог: 53 источника, загрузчик 44 репозиториев. Полные сторонние руководства не вложены; сканы PDF требуют OCR. API Astra зависит от версии сервера и проверяется по вашему Swagger.

Приёмка в контуре включает настоящий Kubernetes, Astra, Qwen, известные инциденты и ожидаемую нагрузку. Фактические локальные проверки — в QA-RU.md.
