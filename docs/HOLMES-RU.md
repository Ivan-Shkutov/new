# HolmesGPT для Pulse 0.16.0

[Полная настройка, бюджеты, обновление bundle, единый Compose и приёмка](AI-STACK-RU.md#holmes-подготовка-обновление-проверка).

Pulse использует проверенный по исходникам контракт Holmes 0.45.0: `/api/info?detail=full` с `auth_enabled=true` и только активными `pulse-readonly`/`skills`; затем `/api/chat` с `ask`, `model`, `conversation_history`, `additional_system_prompt`, `stream=false`. Ответ — непустой `analysis`, журнал tool_calls, без ошибки/незавершённого finish_reason/pending approvals. Имена tools в ответе сами по себе не доказывают правильный диагноз.

Генератор создаёт кластерный read-only токен, отдельный ключ Holmes, wrapper отключения всех builtin toolsets и 16 SKILL.md. Включены процесс расследования, Kubernetes/сети/OOM/хранилища и профили VK Teams, VK Почты, Astra. До финальных рекомендаций агент должен использовать предоставленную документацию либо искать её через `/documents`, не повторять одни проверки и останавливаться при достаточных данных или лимите.

Новый bundle: 8 итераций, 4096 токенов, 180 секунд на запрос к модели; клиент Pulse ждёт 600 секунд. Эти величины редактируются в настройках. Изменения уже существующего bundle применяются отдельной кнопкой «Обновить skills и лимиты» и требуют пересоздания именно этого сервиса. Приватная копия создаётся до обновления; tokens, api_base, model alias, image и Compose сохраняются. Прежний внешний Holmes вне созданного Pulse каталога не меняется.

Кластер читает только разрешённые HTTP API Pulse. Произвольные URL, shell, SQL, kubectl exec и автоматические исправления не доступны. Токен относится к кластеру целиком, не является namespace-only. Базовое расследование Pulse привязано к namespace/name/UID; утверждения модели не становятся фактами только из-за вызова инструмента. Ключи не возвращаются браузеру.

Приёмка: сначала ответ Holmes, затем настоящий nonce-тест «Проверить инструменты», затем известный инцидент и сверка фактов, документов, областей команд и результата. Реальная способность Qwen к tool calling зависит от весов/template/parser. Reasoning parser не подтверждает эту способность.

Сам образ Holmes и веса не входят в release Pulse. В среде разработки предыдущая попытка получить образ из registry завершалась Forbidden; отсутствие запуска реального Holmes нельзя заменить mocks. API-тесты и безопасный генератор не выданы за проверку вашей установки. Для версии, отличной от проверенного контракта, сначала нужна сверка её API и whitelist, а не отключение проверок защиты.
