# Проверки Pulse Clusters 0.11.1

166 pytest прошли; пропусков нет. В Chromium воспроизведён прежний пропуск metrics при HTTP с пустым URL; исправление проверено через настоящий API: конфигурация proxy сохраняется после reload и изменения имени, неполная форма остаётся открытой с видимой ошибкой, несохранённая проверка блокируется, неподтверждённый readback не выдаётся за успех. Внешние данные в визуальных проверках — fixtures.

[Применение исправления](UPDATE-0.11.1-RU.md). Подключение с реального сервера Pulse ещё требует проверки сохранённым reader token. Данные пользователя и его действующая установка отсюда не менялись.
