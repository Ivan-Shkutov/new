# Pulse: краткий контекст

Сверять с git status и реальным сервером. Этот файл не подтверждает production-развёртывание.

- Репозиторий Ivan-Shkutov/new, только Pulse Clusters. Новая версия **0.16.0 / b6c7a21b723d8cad**, рабочая ветка feat/pulse-0.16.0-investigator. Пользователь разрешил правки, аудит, увеличение бюджетов и публикацию GitHub. Последняя известная серверная версия 0.15.1. Сервер p0-app5000: vLLM qwen на двух A30, host port8002; Pulse host-network8090; Caddy8091. Реальный server runtime после переноса `/opt/services/pulse/runtime`, source через `/opt/services/pulse/current`.
- Новый главный интерфейс: ✧ в Обзоре/Ресурсах → единый временный чат в стиле Astra и цветах Pulse. Пункт Диагностика и отдельная страница убраны. Первое открытие пустое, быстрые действия и free follow-up; новый вход/close/Escape очищают transcript. Обычный текст модели принимается через `/sessions/{sid}/messages`. Старые JSON-сценарии `/scenarios` оставлены для совместимости, не смешивать их DTO с chat.
- Проверены 550 pytest и локальная browser/API/Docker/Qdrant/PromQL приёмка; подробности в QA-RU.md. Настоящие Qwen/Holmes/BGE/Peoplehub/Astra не сертифицированы mocks. Пользователь ранее доказал доступность vLLM GET и короткого SSE из Pulse; native adapter использует stream=false, этот тест не устанавливал причину отказа настоящего инцидента.
- `ai_limits.py`: native defaults8192/300sec/context240k chars, валидация диапазонов; Holmes client600sec. `holmes_bundle.py`: default8 model iterations/4096tokens/180sec per-model request, 16 skills; customlimits в bootstrap/refresh. Повышение лимитов не меняет веса/template/GPU. Reasoning parser не равен tool parser.
- `ai_rules/INVESTIGATION.md` и policy v3: этапы расследования, факты/гипотезы, документы до плана, стоп-критерии, шесть разделов первого полного ответа до450 слов, короткий follow-up. Runbooks v4 добавляют OOM, VK mail, Astra. Инструменты только чтения, никаких автоматических кластерных изменений.
- `app.py`: retrieval до генерации, unique D##/source catalogue, scoped FTS+vector, диагностические run_id/error codes/timing/usage when provided. Incident session bound to UID and source config digest. Неполный ответ/ошибка не считается done; факты сохраняются. Для native/cluster реальная приёмка `scripts/check-ai-integration.py` с конкретным problem_id, не synthetic2+2.
- Holmes `/api/info` и `/api/chat` контракт проверен по исходникам0.45.0. Включать только после ответа и nonce tool test. Bootstrap creates runtime/holmes/<cid>, не перегенерирует токены. Refresh делает приватную копию и обновляет собственные rules/budgets без смены URL/ключей/Compose; требует пересоздания того же сервиса. Образ Holmes не включён, registry ранее Forbidden. Разрешены только pulse-readonly/skills; произвольный внешний Holmes не признан подключённым автоматически.
- `knowledge.py`: SQLite authoritative catalogue+FTS, Qdrant; chunks-v2 учитывают Markdown и требуют reindex существующего корпуса. Один embedding model/dimension/revision; current fingerprint. Plaintext fallback lexical может работать при vector error с явным статусом. Kubernetes minor-version filter; VK/Astra version отображается и требует проверки контекста, полный auto product-version selector не заявлен.
- `library.py`: Markdown-only ZIP/TAR/директория, preflight без extraction/exec, ссылки/traversal/лимиты, последовательный API import. Watcher по product folders с manifest.json, wait stable input, reports в runtime/library-reports и UI. До30k members/2GiBexpanded/2MBperMD/500Mcorpuschars. Повторunchanged без embed, fingerprints trigger reindex; отсутствующий в новом архиве документ автоматически не удаляется.
- `deploy/compose.ai.yaml`: pinned Qdrant+CPU Ollama+optional indexer; merge generated Holmes compose possible с правильным project-directory. Loopback16333/11435; GPU не запрошены. Не создавать второй сервис на занятых портах. [AI-STACK-RU.md](AI-STACK-RU.md) содержит все команды.
- `scripts/upgrade-existing.py`: manifest+exactimage preflight; preserves runtime/keys; accepts new or empty backup, not nonempty; optional --current-link switches only after verified new version; rollback restores old source/image/link. [UPDATE-0.16.0-RU.md](UPDATE-0.16.0-RU.md). Complete bundle includes prebuilt amd64 image+wheelhouse, no Qwen weights or external images.
- Новая версия на сервере пользователя ещё не применена. В итоговом сообщении обязательны exact version/build, download, backup/install/check/rollback commands. Не выдавать передачу GitHub/архив за проверку живых сервисов.
